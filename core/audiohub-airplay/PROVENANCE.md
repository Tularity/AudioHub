# AudioHub-owned AirPlay protocol provenance

This file is the source ledger for the AirPlay 2 and classic audio implementation under
`src/protocol`. The implementation is written for AudioHub. Other receivers
are not source dependencies; where their structure or behaviour influenced an
AudioHub expression, that influence and its license are recorded here.

The protocol engine must not contain OmgHax/FairPlay session-key decryption
code, externally sourced secret or copyrightable packet-capture payloads, or
code copied from GPL/LGPL receiver implementations. The single AirPort Express
private-key exception is isolated and attributed in the ledger below and in
the repository `NOTICE.md`; its presence means the complete receiver is not a
clean-room artifact. Locally observed, non-secret protocol headers may be
retained as attributed parser vectors when the ledger below records them
explicitly.
